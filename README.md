# Obsidian Vault — معرض صور خاص وأوفلاين

تطبيق Flutter داكن بالكامل، بواجهة عربية RTL، مبني من تصميم HTML/CSS الأصلي مع نفس لوحة الألوان والخطوط والمسافات. الصور تُستورد من `assets/images` وتُخزّن داخل قاعدة بيانات SQLite محلية — لا يحتاج التطبيق اتصالاً بالإنترنت.

## المزايا

- شاشة قفل برمز PIN (الرمز التجريبي: `1234`) مع اهتزاز عند الخطأ ودخول سلس.
- معرض رئيسي مجمّع حسب التاريخ، مع تحديد متعدد وأزرار مشاركة/مفضلة/حذف تعمل جميعها.
- البحث عن الصور حسب العنوان أو التاريخ في المعرض، الألبومات، والمفضلة.
- ألبومات مع تصفية حسب التصنيف، ألبوم مقفل، وعدّاد صور، وإنشاء ألبوم جديد.
- شاشة ألبوم مع غلاف، تصفية المفضلة، تبديل شبكة 2/3 أعمدة، وعلامة نهاية الألبوم.
- عارض صور متقدم: تكبير بالنقر المزدوج، سحب للأسفل للإغلاق، شريط EXIF، مفضلة، مشاركة، وحذف الصورة الحالية.
- المفضلة، والإعدادات (الأمان، المظهر، الخصوصية، مساحة التخزين).
- أوفلاين 100%: 62 صورة محلية تُخزّن كـ BLOB داخل SQLite، وكل الخطوط داخل `assets/fonts`.
- الصور ديناميكية: المعرض والألبومات والمفضلة والعارض تقرأ من قاعدة البيانات، وأي صورة جديدة في `assets/images` تُضاف تلقائيًا عند التشغيل التالي.
- GitHub Actions لبناء APK تلقائيًا ورفعه كـ Artifact، مع نشر Release عند إنشاء Tag.

## التشغيل

```bash
flutter pub get
flutter run
```

## بناء APK

```bash
flutter build apk --release
```

الملف الناتج:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## GitHub Actions

الـ workflow موجود في:

```text
.github/workflows/build-apk.yml
```

- يعمل عند push إلى `main` أو `master`، أو عند فتح Pull Request، أو يدويًا من `workflow_dispatch`.
- يبني `app-release.apk` ويرفعه كـ Artifact باسم `obsidian-vault-apk`.
- عند push لـ tag يبدأ بـ `v` (مثل `v1.0.1`) يرفق الـ APK تلقائيًا في GitHub Release.

## ملاحظات

- الـ APK الحالي موقّع بمفتاح debug الافتراضي، وهو مناسب للاستخدام الشخصي والتثبيت المباشر، وليس للنشر على المتاجر.
- لإضافة صور جديدة: ضعها في `assets/images/` فقط، وستُستورد تلقائيًا إلى SQLite عند التشغيل التالي.
- قاعدة البيانات: `obsidian_vault.db` داخل مجلد قواعد بيانات التطبيق، وتُملأ من الأصول عند أول تشغيل. استبدال صورة بنفس الاسم يحتاج مسح بيانات التطبيق لإعادة استيرادها.
- الخطوط: Space Grotesk، Noto Sans، Noto Sans Arabic، Space Mono.
- بنية الكود: `lib/screens` للشاشات، `lib/widgets` للمكوّنات المشتركة، `lib/models` للنماذج، `lib/data/gallery_repository.dart` لطبقة SQLite، `lib/theme.dart` للثيم.
